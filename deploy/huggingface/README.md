# Nabz

An offline health monitor for astronauts on long missions. NASA Space Apps Challenge 2026, team NOVA TRIO.

Demo crew codes: Sara `4120`, Mateo `7316`, Elena `2468`, Kenji `9053`. Emergency guides open without sign-in.

All crew data is synthetic. Data you add resets when the Space restarts. Decision support, not a diagnosis.

Source and full documentation: the team's GitHub repository.
